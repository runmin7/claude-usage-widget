작동 원리

사용량을 어디서 가져오는가

Claude Code가 로그인할 때 저장해둔 OAuth 토큰을 그대로 빌려 씁니다. 이 프로그램은 별도 로그인이나 API 키 발급이 필요 없고, 토큰을 읽기만 합니다.

토큰은 읽기만 합니다. 토큰 갱신을 직접 하거나 자격증명 파일에 쓰지 않습니다. Claude Code의 자체 갱신과 부딪히면 로그아웃될 수 있기 때문입니다. 대신 토큰이 만료되면 만료 상태만 표시하고, 갱신되면 다음 조회에서 복구됩니다.

토큰을 갱신하는 것은 터미널의 claude 명령(CLI)뿐입니다. 데스크톱 앱은 자격증명을 별도 저장소(브라우저 쿠키)에 두기 때문에, 앱에서 아무리 작업해도 이 파일은 갱신되지 않습니다. 액세스 토큰 수명이 8시간이라 CLI를 하루 넘게 쓰지 않으면 표시가 멈춥니다. 터미널에서 claude로 아무 작업이나 한 번 하면 바로 복구됩니다. 만료된 토큰으로는 요청을 아예 보내지 않으므로 그 상태가 서버 차단으로 번지지는 않습니다.

설치 순서

  1. 01 ZIP의 차단을 먼저 해제합니다 압축을 풀기 전에 ZIP 파일 우클릭 → 속성 → 아래쪽의 차단 해제에 체크. 순서가 중요합니다 — 먼저 풀면 파일마다 따로 해제해야 합니다. 해제하지 않아도 실행 자체는 되지만, 처음 실행할 때 보안 경고가 뜰 수 있습니다.
  2. 02 원하는 폴더에 압축을 풉니다 ClaudeUsageMonitor.ps1, start.vbs, guide.html, MODULES.md와 lib 폴더가 들어 있습니다. lib 폴더를 같이 풀어야 실행됩니다. 위치는 어디든 상관없지만, 나중에 옮기지 않을 곳에 두는 편이 좋습니다.
  3. 03 start.vbs를 실행합니다 창은 뜨지 않습니다. 트레이에 사용률 숫자가 그려진 아이콘이 나타나면 정상입니다. config.json은 이때 자동으로 만들어집니다.
  4. 04 자동 시작을 켭니다 트레이 우클릭 → 로그온 시 자동 시작. 이후 폴더를 옮기면 바로가기가 깨지므로 옮긴 뒤 다시 켜야 합니다.

메일로는 보내지 마세요. start.vbs는 Outlook이 기본으로 차단하는 확장자이고, 사내 메일 보안이 ZIP 안까지 검사하면 첨부가 제거되거나 격리됩니다. 사내 공유 폴더·SharePoint·Teams로 전달하는 편이 확실합니다.

WSH(.vbs)를 정책으로 막아둔 PC라면 런처가 동작하지 않습니다. 그때는 아래 내용으로 바로가기를 만들어 대신 쓰면 됩니다.

계정을 여러 개 쓰는 경우에만 예외가 있습니다. CLAUDE_CONFIG_DIR 환경변수로 Claude 설정 위치를 옮겨 둔 PC라면, 이 프로그램도 그 변수를 따라갑니다. 변수가 없거나 가리키는 폴더가 없으면 기본 경로를 씁니다. 역시 손댈 것이 없습니다.

실행 후 위젯 맨 위에 빨간 글씨로 “자격증명을 읽을 수 없습니다”라고 나오면, 그 PC에서 Claude Code에 로그인하지 않은 것입니다. 한 번 로그인하면 다음 갱신에서 잡힙니다.

알림

세션과 주간 각각 50% · 70% · 90% · 95%를 넘을 때 한 번씩 알림이 뜹니다. 한 번에 여러 단계를 뛰어넘으면 가장 높은 것만 알립니다. 한도가 리셋되면 다시 처음부터 알릴 준비를 합니다.

이미 지나간 구간은 알리지 않습니다. 프로그램을 58%에서 켰다면 50% 초과는 이미 지난 일이라 알림이 뜨지 않고, 그 뒤에 넘어서는 70% 부터 알립니다. 켤 때마다 지난 구간이 쏟아지는 것을 막기 위한 동작입니다.

90%와 95%는 같은 빨간색을 씁니다. 색은 네 단계(여유·주의·경고·위험)뿐이고 95%는 그중 위험에 함께 들어갑니다. 한도가 거의 다 찼을 때 한 번 더 짚어주기 위한 알림이라, 색이 아니라 알림으로만 구분됩니다.

주의사항

이 프로그램은 비공식 API에 의존합니다

사용량을 가져오는 /api/oauth/usage는 Anthropic이 문서화하지 않은 엔드포인트입니다. Claude Code와 Claude 앱이 내부적으로 쓰는 것을 그대로 호출하는 방식이고, 공개된 규격이나 지원 약속이 없습니다. 실제로 이 엔드포인트의 동작을 문제 삼은 이슈는 Anthropic이 대응하지 않기로 종료한 상태입니다.

따라서 다음을 전제로 쓰셔야 합니다.

  1. 01 예고 없이 깨질 수 있습니다 응답 형식이 바뀌거나 엔드포인트가 사라지면 표시가 멈춥니다. 필드가 일부 빠지는 정도는 견디도록 만들었지만, 엔드포인트 자체가 없어지면 대응 방법이 없습니다.
  2. 02 자주 요청하면 막힙니다 요청 제한이 엄격하고 한 번 걸리면 잘 풀리지 않습니다. 그래서 기본 간격을 5분으로 잡았습니다. pollActiveSeconds를 줄이는 것은 권하지 않습니다.
  3. 03 공식 대안은 이 용도에 맞지 않습니다 문서화된 Claude Code Analytics API는 관리자 키가 필요하고 Team 플랜은 지원하지 않으며, 일별 집계라 5시간 롤링 한도의 잔량을 알 수 없습니다.
  4. 04 Anthropic의 공식 제품이 아닙니다 사내에서 쓰기 위해 만든 유틸입니다. 표시된 값이 이상하면 Claude 앱의 설정 → 사용량 화면과 비교해 보세요.
